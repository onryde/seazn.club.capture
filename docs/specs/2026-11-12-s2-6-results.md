(`2026-11-11-s2-6-volleyball-design.md`, rulings 170–189) and S2 §10. Staging (`stg.seazn.club`), the owner's OnePlus
NE2211 (Android 16, 1080 × 2412, density 480, so 360 dp wide; 320 dp by `wm size 640x1280` with `wm density 320`, then

(`.superpowers/sdd/2026-11-11-s2-6-volleyball/progress.md`), which is git-excluded; this document is the record that

set to 15, no substitutions), rally by rally with the serve side, the deciding-set toss, timeouts, substitutions with
the players on the team sheet (indoor), the four-step sanction ladder, the set score and a History row for each. It
never sends a forfeit, a settle or an abandon, and it has no libero (S2-6b, the owner's, ruling 171). The pad is the
owner's layout A (ruling 178): Timeout, Sub, More and Set score on the tools row, each half's counts on its foot,
Sanction in More.

## Changes for other sports

Each is generic and was declared in design §6; the tests of the sports named run in the same suites.

- **The bootstrap re-read** (ruling 181; `scoringMatchReads`, `scoringMatch`, `scoringMatchState`, `usePadMatchParts`):
  the match's teams, players and config are read again on foreground and when a player-listing sheet opens, paced by
  `BOOTSTRAP_PACE_MS` (15 s). Every sport's fold input changes; the unfoldable card shows when a named person has left
  the sheet. Pinned for football in `useFootballMatch.people.test.tsx` (cricket and the others by the generic fold).
  The ledger notes that unfoldable-on-drop is asserted for football only.
- **Cricket asks `peopleSheet`** in its setup, Out and More flows (`useCricketSetup`, `useCricketMatch`,
  `useCricketSheets`), after its guards; football's sheets hook passes the same ask. `usePadTaps` gained `bounced(tap)`.
- **`keepingNamed` was added and removed** within the branch (ruling 191); it is not in the tree.
- **`ToolRow` takes an optional `slots`** and `PadView` an optional `toolSlots` (F3): empty flex cells after the tools,
  none when there are no tools. Opt-in; no other sport sets it.
- **`PadHalf.foot`** (a `PadFoot`, type only in `padView.ts`) and `ScoreHalf` support for it: opt-in, drawn in the
  half's left slot; no other sport sets it.
- **`setBasedFold` takes an optional `lineupsOf`** (volleyball folds with the server's lineup, ruling 186); badminton and
  table tennis keep theirs, and that they differ from the server is a finding, not changed here.
- **`fakeScoringPort`** gained the volleyball key and a fake `decided()` that surfaces `EngineError`.
- **Lint:** `SPORT_MODULES` and `SPORT_OWN_FILES` gain volleyball in both casings; `sportBoundary.test.ts` proves it.
